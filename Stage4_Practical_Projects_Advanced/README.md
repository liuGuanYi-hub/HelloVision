## 📦 环境准备

### 快速开始

```bash
# 1. 安装所有依赖
pip install -r requirements.txt

# 2. 验证环境
python test_installation.py

# 3. 开始学习
cd 4.1_图像分类实战
python Practice.py
```

### 详细配置

查看 [环境配置指南](environment_setup.md) 了解：
- Python 虚拟环境配置
- CUDA 和 GPU 支持
- 依赖包详细安装步骤
- 常见问题解决

### 硬件要求
- **内存**：至少 8GB RAM（推荐 16GB）
- **GPU**：建议使用 NVIDIA 显卡（GTX 1060 以上，可选）
- **存储**：预留 50GB+ 空间存放数据集
