# 4.6 综合项目：AI视觉流水线看板

## 项目目标

将4.2-4.5训练的四个模型串联起来，实现"一张图输入 → 全流程视觉分析 → 综合展示输出"的多模型协同视觉系统。

## 功能设计

### 输入
- 任意一张图片

### 处理流程（流水线）
```
原图 
  ├─→ YOLO目标检测 ──────────────→ 检测框标注图 + 物体列表
  ├─→ U-Net图像分割 ─────────────→ 前景蒙版 + 分割可视化
  ├─→ ResNet图像分类 ────────────→ 类别标签 + 置信度
  └─→ Gatys风格迁移 ─────────────→ 风格化结果图（可选）
```

### 输出
- 一张拼接展示图（4个子结果 + 综合分析文字）
- 或分图展示模式

## 技术方案

### 框架
- PyTorch + OpenCV + PIL + Matplotlib (Agg模式)

### 模块设计
1. **ModelLoader** - 统一加载4个模型
2. **YOLOWrapper** - 包装YOLO推理，输出检测框
3. **UNetWrapper** - 包装U-Net推理，输出分割蒙版
4. **ResNetWrapper** - 包装ResNet推理，输出分类结果
5. **StyleTransferWrapper** - 包装Gatys风格迁移
6. **Pipeline** - 串联4个模型，统一调度
7. **Visualizer** - 拼接结果为综合展示图
