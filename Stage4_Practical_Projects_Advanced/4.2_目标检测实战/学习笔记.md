## 1. 目标检测基础

### 1.1 什么是目标检测？

目标检测 = **定位** + **识别**

**与图像分类的区别**：
- **图像分类**: 这张图是什么？（整张图一个标签）
- **目标检测**: 图中有什么物体？在哪里？（多个物体 + 位置）

**示例对比**：
```
图像分类：
输入：一张有猫和狗的图片
输出："猫"（只能识别一个主要物体）

目标检测：
输入：一张有猫和狗的图片
输出：
  - 猫 (置信度 0.95, 位置 [x1, y1, x2, y2])
  - 狗 (置信度 0.92, 位置 [x1, y1, x2, y2])
  - 沙发 (置信度 0.88, 位置 [x1, y1, x2, y2])
```

### 1.2 核心概念

#### 边界框（Bounding Box）
用矩形框标注物体位置：
- `(x1, y1)`: 左上角坐标
- `(x2, y2)`: 右下角坐标
- 或 `(x_center, y_center, width, height)`: 中心点 + 宽高

#### 锚点（Anchor Boxes）
预定义的框形状，用于匹配不同长宽比的物体：
- 高瘦的锚点：适合人、瓶子
- 扁平的锚点：适合车、桌子
- 方形的锚点：适合猫、狗、人脸

#### IoU（Intersection over Union）
评估检测准确度的指标：
```
IoU = 预测框 ∩ 真实框 / 预测框 ∪ 真实框

IoU > 0.5: 通常认为是成功检测
IoU = 1: 完美重合
IoU = 0: 完全不重叠
```

## 2. YOLO 系列简介

### 2.1 YOLO 发展史

```
2015: YOLOv1 - 开山之作，实时检测的突破
2016: YOLOv2 (YOLO9000) - 引入锚点机制
2018: YOLOv3 - 多尺度预测，性能大幅提升
2020: YOLOv4 - 多种优化技巧集成
2021: YOLOv5 - Ultralytics 发布，易用性极大提升
2023: YOLOv8 - 最新一代，精度速度双提升
```

### 2.2 YOLO 核心思想

**One-Stage 检测器**：
- 直接从图像像素到边界框和类别概率
- 不需要区域提议（Region Proposal）
- 速度极快，适合实时应用

**YOLO 检测流程**：
```
输入图像
    ↓
调整大小（如 640x640）
    ↓
CNN 骨干网络提取特征
    ↓
特征金字塔（多尺度特征）
    ↓
检测头预测：
  - 边界框坐标
  - 物体置信度
  - 类别概率
    ↓
非极大值抑制（NMS）去除重复框
    ↓
输出最终检测结果
```

### 2.3 YOLOv8 架构

**YOLOv8 的改进**：
1. **Backbone**: C2f 模块替代 C3，更轻量高效
2. **Head**: 解耦头设计，分类和回归分离
3. **Anchor-Free**: 无需锚点，简化设计
4. **损失函数**: 新的分类损失 VFL + 回归损失 CIoU

**模型规格**：
| 模型 | 参数量 | 速度 | 精度 | 适用场景 |
|------|--------|------|------|----------|
| YOLOv8n | 3.2M | 最快 | 中等 | 移动端、实时 |
| YOLOv8s | 11.2M | 快 | 良好 | 平衡性能 |
| YOLOv8m | 25.9M | 中等 | 很好 | 精度优先 |
| YOLOv8l | 43.7M | 慢 | 优秀 | 离线处理 |
| YOLOv8x | 68.2M | 最慢 | 最佳 | 最高精度 |

## 3. YOLOv8 使用教程

### 3.1 安装 ultralytics

```bash
pip install ultralytics
```

### 3.2 使用预训练模型推理

```python
from ultralytics import YOLO

# 加载预训练模型
model = YOLO('yolov8n.pt')  # COCO 数据集预训练

# 单张图片检测
results = model('image.jpg')

# 显示结果
for result in results:
    boxes = result.boxes  # 边界框
    probs = result.probs  # 分类概率（如果是分类任务）
    
    # 绘制结果
    result.show()  # 弹窗显示
    result.save('result.jpg')  # 保存结果
```

### 3.3 检测结果解析

```python
from ultralytics import YOLO

model = YOLO('yolov8n.pt')
results = model('image.jpg')

for result in results:
    boxes = result.boxes
    
    print(f"检测到 {len(boxes)} 个物体")
    
    for box in boxes:
        # 边界框坐标
        x1, y1, x2, y2 = box.xyxy[0].tolist()
        
        # 类别 ID 和名称
        cls_id = int(box.cls[0])
        cls_name = model.names[cls_id]
        
        # 置信度
        confidence = float(box.conf[0])
        
        print(f"类别：{cls_name}, 置信度：{confidence:.2f}")
        print(f"位置：[{x1:.1f}, {y1:.1f}, {x2:.1f}, {y2:.1f}]")
```

### 3.4 批量检测

```python
from ultralytics import YOLO

model = YOLO('yolov8n.pt')

# 检测多张图片
images = ['image1.jpg', 'image2.jpg', 'image3.jpg']
results = model(images)

# 保存所有结果
for i, result in enumerate(results):
    result.save(f'result_{i}.jpg')
```

## 4. 自定义数据集标注

### 4.1 YOLO 格式说明

**目录结构**：
```
dataset/
├── images/
│   ├── train/
│   │   ├── img1.jpg
│   │   └── img2.jpg
│   └── val/
│       ├── img3.jpg
│       └── img4.jpg
├── labels/
│   ├── train/
│   │   ├── img1.txt
│   │   └── img2.txt
│   └── val/
│       ├── img3.txt
│       └── img4.txt
└── data.yaml
```

**标签文件格式**（.txt）：
```
# 每行一个物体：class x_center y_center width height
# 坐标已归一化到 [0, 1]
0 0.5 0.5 0.2 0.3  # 类别 0，中心 (0.5, 0.5)，宽 0.2，高 0.3
1 0.3 0.7 0.1 0.15 # 类别 1
```

**data.yaml 配置**：
```yaml
# 数据集路径
path: /path/to/dataset
train: images/train
val: images/val

# 类别信息
nc: 2  # 类别数量
names: ['cat', 'dog']  # 类别名称
```

### 4.3 数据转换脚本

```python
import os
import xml.etree.ElementTree as ET

def convert_voc_to_yolo(xml_file, txt_file, classes):
    """将 VOC 格式（XML）转换为 YOLO 格式（TXT）"""
    tree = ET.parse(xml_file)
    root = tree.getroot()
    
    size = root.find('size')
    width = int(size.find('width').text)
    height = int(size.find('height').text)
    
    with open(txt_file, 'w') as f:
        for obj in root.findall('object'):
            cls_name = obj.find('name').text
            cls_id = classes.index(cls_name)
            
            bbox = obj.find('bndbox')
            x1 = float(bbox.find('xmin').text)
            y1 = float(bbox.find('ymin').text)
            x2 = float(bbox.find('xmax').text)
            y2 = float(bbox.find('ymax').text)
            
            # 转换为归一化中心坐标
            x_center = (x1 + x2) / 2.0 / width
            y_center = (y1 + y2) / 2.0 / height
            w = (x2 - x1) / width
            h = (y2 - y1) / height
            
            f.write(f"{cls_id} {x_center:.6f} {y_center:.6f} {w:.6f} {h:.6f}\n")

# 使用示例
classes = ['cat', 'dog']
convert_voc_to_yolo('annotation.xml', 'label.txt', classes)
```

## 5. 训练自定义模型

### 5.1 训练配置

```python
from ultralytics import YOLO

# 加载模型
model = YOLO('yolov8n.pt')  # 加载预训练模型

# 训练配置
train_args = {
    'data': 'data.yaml',        # 数据集配置
    'epochs': 100,              # 训练轮数
    'imgsz': 640,               # 输入图像大小
    'batch': 16,                # 批次大小
    'device': '0',              # GPU 设备（'cpu' 或 '0'）
    'workers': 4,               # 数据加载线程数
    'optimizer': 'SGD',         # 优化器
    'lr0': 0.01,                # 初始学习率
    'patience': 50,             # 早停耐心值
    'save': True,               # 保存 checkpoint
    'project': 'runs/detect',   # 保存路径
    'name': 'exp',              # 实验名称
}

# 开始训练
results = model.train(**train_args)
```

## 6. 实时检测实现

### 6.1 摄像头实时检测

```python
from ultralytics import YOLO
import cv2

# 加载模型
model = YOLO('yolov8n.pt')

# 打开摄像头
cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret:
        break
    
    # 检测
    results = model(frame, verbose=False)
    
    # 绘制结果
    annotated_frame = results[0].plot()
    
    # 显示
    cv2.imshow('YOLOv8 Detection', annotated_frame)
    
    # 按 q 退出
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
```

### 6.2 视频文件检测

```python
from ultralytics import YOLO
import cv2

model = YOLO('yolov8n.pt')

# 打开视频文件
cap = cv2.VideoCapture('video.mp4')

# 获取视频信息
fps = cap.get(cv2.CAP_PROP_FPS)
width = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
height = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))

# 创建视频写入器
fourcc = cv2.VideoWriter_fourcc(*'mp4v')
out = cv2.VideoWriter('output.mp4', fourcc, fps, (width, height))

while True:
    ret, frame = cap.read()
    if not ret:
        break
    
    # 检测
    results = model(frame, verbose=False)
    
    # 绘制并保存
    annotated_frame = results[0].plot()
    out.write(annotated_frame)

cap.release()
out.release()
print("视频处理完成！")
```
