## 1. 图像分割基础

### 1.1 什么是图像分割？

图像分割 = **像素级分类**

**与分类、检测的对比**：
```
图像分类：
输入：一张图
输出：一个标签（猫）

目标检测：
输入：一张图
输出：多个边界框 + 类别
  - 猫 [x1, y1, x2, y2]
  - 狗 [x1, y1, x2, y2]

图像分割：
输入：一张图
输出：每个像素的类别
  - 像素 (0,0): 猫
  - 像素 (0,1): 猫
  - 像素 (0,2): 背景
  - ...
```

### 1.2 应用场景

- 🏥 **医学影像**：肿瘤分割、器官分割
- 🚗 **自动驾驶**：道路分割、可行驶区域检测
- 🛰️ **遥感图像**：土地利用分类、建筑物提取
- 📱 **人像模式**：背景虚化、抠图
- 🎨 **图像编辑**：智能选择、内容填充

### 1.3 技术挑战

- **细节保留**：如何保持物体边缘的精细度
- **多尺度**：如何处理不同大小的物体
- **实时性**：如何平衡精度和速度
- **类别不平衡**：如何处理大小差异大的类别

## 2. 语义分割 vs 实例分割

### 2.1 语义分割（Semantic Segmentation）

**定义**：为每个像素分配类别标签

**特点**：
- 不区分同一类别的不同实例
- 所有猫都被标记为"猫"

**示例**：
```
输入：两只猫的图像
输出：
  - 猫 1 的像素 → 类别"猫"
  - 猫 2 的像素 → 类别"猫"
  - 背景像素 → 类别"背景"
```

### 2.2 实例分割（Instance Segmentation）

**定义**：不仅区分类别，还要区分不同实例

**特点**：
- 区分同一类别的不同个体
- 每只猫都有独立的 ID

**示例**：
```
输入：两只猫的图像
输出：
  - 猫 1 的像素 → 实例"猫_1"
  - 猫 2 的像素 → 实例"猫_2"
  - 背景像素 → 类别"背景"
```

### 2.3 对比总结

| 特性 | 语义分割 | 实例分割 |
|------|---------|---------|
| 区分实例 | ❌ 否 | ✅ 是 |
| 复杂度 | 较低 | 较高 |
| 速度 | 较快 | 较慢 |
| 应用 | 场景理解 | 目标计数 |
| 代表模型 | U-Net, DeepLab | Mask R-CNN |

## 3. 经典网络架构

### 3.1 FCN（Fully Convolutional Networks）

**开山之作**（2015）

**核心思想**：
- 将全连接层改为卷积层
- 实现任意尺寸输入
- 使用转置卷积上采样

**架构**：
```
输入图像
    ↓
VGG 骨干网络（卷积 + 池化）
    ↓
全卷积层
    ↓
转置卷积（上采样）
    ↓
输出分割图
```

**贡献**：
- ✅ 首个端到端的语义分割网络
- ✅ 开创了编码器 - 解码器结构
- ✅ 证明了全卷积网络的有效性

### 3.2 U-Net

**医学图像分割王者**（2015）

**架构特点**：
- 对称的 U 型结构
- 跳跃连接（Skip Connections）
- 多尺度特征融合

**U-Net 结构**：
```
输入
  ↓
[编码器]           [解码器]
Conv → Pool        UpConv
Conv → Pool   →→→  Conv (拼接)
Conv → Pool   →→→  Conv (拼接)
    ↓              ↓
  Bottleneck   →→→  UpConv
              ↓
            输出
```

**跳跃连接的作用**：
- 保留空间细节信息
- 融合浅层和深层特征
- 改善梯度流动

### 3.3 DeepLab 系列

**DeepLabv1** (2015)：
- 引入空洞卷积（Atrous Convolution）
- 使用 CRF 后处理优化边界

**DeepLabv2** (2017)：
- 空洞空间金字塔池化（ASPP）
- 多尺度信息融合

**DeepLabv3** (2017)：
- 改进的 ASPP
- 更好的多尺度处理

**DeepLabv3+** (2018)：
- 加入解码器结构
- 恢复物体边界细节

**DeepLabv3+ 架构**：
```
输入
  ↓
Xception 骨干网络
  ↓
ASPP（空洞空间金字塔池化）
  ↓      ↑
  ↓   低层特征（细节）
  ↓      ↓
  ↓    拼接
  ↓      ↓
  ↓   卷积
  ↓      ↓
  双线性插值上采样
  ↓
输出
```

## 4. U-Net 详解

### 4.1 完整架构

```
层级结构：

Layer 1 (输入):          572x572x3
  ↓ Conv3x3 + ReLU
Layer 2:                570x570x64
  ↓ Conv3x3 + ReLU
Layer 3:                568x568x64
  ↓ MaxPool2x2          (保存用于跳跃连接)
Layer 4:                284x284x128
  ↓ Conv3x3 + ReLU
Layer 5:                282x282x128
  ↓ MaxPool2x2          (保存)
Layer 6:                140x140x256
  ↓ Conv3x3 + ReLU
Layer 7:                138x138x256
  ↓ MaxPool2x2          (保存)
Layer 8:                68x68x512
  ↓ Conv3x3 + ReLU
Layer 9:                66x66x512
  ↓ MaxPool2x2          (保存)
Layer 10:               32x32x1024
  ↓ Conv3x3 + ReLU
Layer 11:               30x30x1024
  ↓ UpConv2x2
Layer 12:               60x60x512
  ← 拼接 Layer 9 (66x66x512)
Layer 13:               60x60x1024
  ↓ Conv3x3 + ReLU
Layer 14:               58x58x512
  ↓ UpConv2x2
... (对称结构)
  ↓
输出：388x388x2 (二分类)
```

### 4.2 PyTorch 实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class DoubleConv(nn.Module):
    """(convolution => [BN] => ReLU) * 2"""
    
    def __init__(self, in_channels, out_channels, mid_channels=None):
        super().__init__()
        if not mid_channels:
            mid_channels = out_channels
        self.double_conv = nn.Sequential(
            nn.Conv2d(in_channels, mid_channels, kernel_size=3, padding=1),
            nn.BatchNorm2d(mid_channels),
            nn.ReLU(inplace=True),
            nn.Conv2d(mid_channels, out_channels, kernel_size=3, padding=1),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True)
        )

    def forward(self, x):
        return self.double_conv(x)


class Down(nn.Module):
    """Downscaling with maxpool then double conv"""
    
    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.maxpool_conv = nn.Sequential(
            nn.MaxPool2d(2),
            DoubleConv(in_channels, out_channels)
        )

    def forward(self, x):
        return self.maxpool_conv(x)


class Up(nn.Module):
    """Upscaling then double conv"""
    
    def __init__(self, in_channels, out_channels, bilinear=True):
        super().__init__()
        
        if bilinear:
            self.up = nn.Upsample(scale_factor=2, mode='bilinear', align_corners=True)
        else:
            self.up = nn.ConvTranspose2d(in_channels, in_channels // 2, kernel_size=2, stride=2)
        
        self.conv = DoubleConv(in_channels, out_channels)

    def forward(self, x1, x2):
        x1 = self.up(x1)
        
        # 处理尺寸差异
        diffY = x2.size()[2] - x1.size()[2]
        diffX = x2.size()[3] - x1.size()[3]
        
        x1 = F.pad(x1, [diffX // 2, diffX - diffX // 2,
                        diffY // 2, diffY - diffY // 2])
        
        x = torch.cat([x2, x1], dim=1)
        return self.conv(x)


class UNet(nn.Module):
    def __init__(self, n_channels=3, n_classes=1, bilinear=True):
        super(UNet, self).__init__()
        self.n_channels = n_channels
        self.n_classes = n_classes
        self.bilinear = bilinear

        self.inc = DoubleConv(n_channels, 64)
        self.down1 = Down(64, 128)
        self.down2 = Down(128, 256)
        self.down3 = Down(256, 512)
        factor = 2 if bilinear else 1
        self.down4 = Down(512, 1024 // factor)
        self.up1 = Up(1024, 512 // factor, bilinear)
        self.up2 = Up(512, 256 // factor, bilinear)
        self.up3 = Up(256, 128 // factor, bilinear)
        self.up4 = Up(128, 64, bilinear)
        self.outc = nn.Conv2d(64, n_classes, kernel_size=1)

    def forward(self, x):
        x1 = self.inc(x)
        x2 = self.down1(x1)
        x3 = self.down2(x2)
        x4 = self.down3(x3)
        x5 = self.down4(x4)
        x = self.up1(x5, x4)
        x = self.up2(x, x3)
        x = self.up3(x, x2)
        x = self.up4(x, x1)
        logits = self.outc(x)
        return logits
```

## 5. DeepLab 系列

### 5.1 空洞卷积（Atrous Convolution）

**传统卷积 vs 空洞卷积**：

```
传统卷积 (3x3, rate=1):
[1][1][1]
[1][x][1]
[1][1][1]
感受野：3x3

空洞卷积 (3x3, rate=2):
[1]   [1]   [1]
      |
[1]   [x]   [1]
      |
[1]   [1]   [1]
感受野：5x5（参数不变！）
```

**优势**：
- ✅ 增大感受野，不增加参数量
- ✅ 保持分辨率，不丢失细节
- ✅ 多尺度信息捕获

### 5.2 ASPP（Atrous Spatial Pyramid Pooling）

**核心思想**：使用不同采样率的空洞卷积并行提取多尺度特征

```
输入特征图
    ↓
    ├─→ 1x1 卷积 (rate=1)
    ├─→ 3x3 空洞卷积 (rate=6)
    ├─→ 3x3 空洞卷积 (rate=12)
    ├─→ 3x3 空洞卷积 (rate=18)
    └─→ 全局平均池化 + 1x1 卷积
    ↓
    拼接所有特征
    ↓
    1x1 卷积融合
    ↓
    输出
```

**作用**：
- 捕获多尺度信息
- 适应不同大小的物体
- 增大感受野

**标注格式**：

- 掩码：PNG（单通道，像素值为类别 ID）
- 类别文件：每行一个类别名称

### 6.2 数据集类

```python
from torch.utils.data import Dataset
from PIL import Image
import os
import torch

class SegmentationDataset(Dataset):
    def __init__(self, images_dir, masks_dir, transform=None):
        self.images_dir = images_dir
        self.masks_dir = masks_dir
        self.transform = transform
        self.images = sorted(os.listdir(images_dir))
        
    def __len__(self):
        return len(self.images)
    
    def __getitem__(self, idx):
        img_name = self.images[idx]
        
        # 加载图像和掩码
        img_path = os.path.join(self.images_dir, img_name)
        mask_path = os.path.join(self.masks_dir, img_name.replace('.jpg', '.png'))
        
        image = Image.open(img_path).convert('RGB')
        mask = Image.open(mask_path)
        
        # 应用变换
        if self.transform:
            transformed = self.transform(image=image, mask=mask)
            image = transformed['image']
            mask = transformed['mask']
        
        return image, mask
```

### 6.3 训练配置

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import transforms

# 超参数
BATCH_SIZE = 8
LEARNING_RATE = 0.001
NUM_EPOCHS = 100
IMG_SIZE = 256
NUM_CLASSES = 2

# 数据变换
train_transform = transforms.Compose([
    transforms.Resize((IMG_SIZE, IMG_SIZE)),
    transforms.ToTensor(),
    transforms.Normalize([0.485, 0.456, 0.406], 
                        [0.229, 0.224, 0.225])
])

# 创建数据集
train_dataset = SegmentationDataset(
    images_dir='dataset/images/train',
    masks_dir='dataset/masks/train',
    transform=train_transform
)

# 数据加载器
train_loader = DataLoader(
    train_dataset,
    batch_size=BATCH_SIZE,
    shuffle=True,
    num_workers=4
)

# 模型
model = UNet(n_channels=3, n_classes=NUM_CLASSES)

# 损失函数
criterion = nn.CrossEntropyLoss()

# 优化器
optimizer = torch.optim.Adam(model.parameters(), lr=LEARNING_RATE)

# 训练循环
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model.to(device)

for epoch in range(NUM_EPOCHS):
    model.train()
    running_loss = 0.0
    
    for images, masks in train_loader:
        images = images.to(device)
        masks = masks.to(device)
        
        # 前向传播
        outputs = model(images)
        
        # 计算损失
        loss = criterion(outputs, masks)
        
        # 反向传播
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        running_loss += loss.item()
    
    print(f'Epoch [{epoch+1}/{NUM_EPOCHS}], Loss: {running_loss/len(train_loader):.4f}')

print('训练完成！')
```

### 6.4 评估指标

**像素准确率（Pixel Accuracy）**：
```python
def pixel_accuracy(outputs, masks):
    _, predicted = torch.max(outputs, 1)
    correct = (predicted == masks).sum().item()
    total = masks.numel()
    return correct / total
```

**IoU（Intersection over Union）**：
```python
def iou_score(outputs, masks, class_idx):
    _, predicted = torch.max(outputs, 1)
    
    # 二值化
    pred_binary = (predicted == class_idx).float()
    true_binary = (masks == class_idx).float()
    
    # 计算交集和并集
    intersection = (pred_binary * true_binary).sum()
    union = pred_binary.sum() + true_binary.sum() - intersection
    
    iou = (intersection + 1e-6) / (union + 1e-6)
    return iou.item()
```

**Dice Coefficient**：
```python
def dice_coefficient(outputs, masks, class_idx):
    _, predicted = torch.max(outputs, 1)
    
    pred_binary = (predicted == class_idx).float()
    true_binary = (masks == class_idx).float()
    
    intersection = (pred_binary * true_binary).sum()
    dice = (2. * intersection + 1e-6) / (pred_binary.sum() + true_binary.sum() + 1e-6)
    
    return dice.item()
```
