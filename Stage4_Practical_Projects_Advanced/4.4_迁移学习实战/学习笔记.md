## 1. 迁移学习基础

### 1.1 什么是迁移学习？

**定义**：将在一个任务（源任务）上学到的知识，应用到另一个相关任务（目标任务）中。

**类比**：
```
学会骑自行车 → 更容易学摩托车
学会钢琴 → 更容易学电子琴
学会 ImageNet 分类 → 更容易学医学图像分类
```

### 1.2 迁移学习的优势

**传统深度学习**：
- 需要大量标注数据（10 万 + 图片）
- 训练时间长（几天到几周）
- 计算资源需求大（多 GPU）

**迁移学习**：
- ✅ 少量数据即可（100-1000 图片）
- ✅ 训练时间短（几小时）
- ✅ 单 GPU 甚至 CPU 即可
- ✅ 准确率更高（预训练权重）

### 1.3 适用场景

- **数据量少**：每类只有几十到几百张图片
- **领域相似**：目标领域与 ImageNet 相似
- **快速原型**：需要快速验证想法
- **资源有限**：没有大量 GPU 资源

## 2. 为什么需要迁移学习？

### 2.1 CNN 学到了什么？

**浅层（Layer 1-2）**：
- 边缘检测器
- 角点检测器
- 颜色特征
- 纹理特征

**中层（Layer 3-4）**：
- 简单形状
- 物体部件
- 纹理模式

**深层（Layer 5+）**：
- 复杂物体
- 语义信息
- 类别特征

**关键发现**：
- 浅层特征通用性强（可迁移）
- 深层特征任务相关（需调整）

### 2.2 数据量 vs 性能

```
数据量      从零训练    迁移学习
100 张      50%        85% ⭐
1000 张     70%        92% ⭐
10000 张    85%        95% ⭐
100000 张   92%        96%
```

**结论**：数据越少，迁移学习优势越明显！

## 3. 迁移学习策略

### 3.1 策略 1：特征提取（Feature Extraction）

**方法**：
- 冻结所有卷积层
- 只训练最后的分类层
- 将 CNN 作为固定特征提取器

**架构**：
```
输入图像
    ↓
[预训练 CNN] (冻结)
    ↓
固定特征向量
    ↓
[新分类器] (训练)
    ↓
输出类别
```

**代码示例**：
```python
import torch
from torchvision import models

# 加载预训练模型
model = models.resnet50(weights=models.ResNet50_Weights.IMAGENET1K_V1)

# 冻结所有参数
for param in model.parameters():
    param.requires_grad = False

# 替换最后的全连接层
num_features = model.fc.in_features
model.fc = torch.nn.Linear(num_features, num_classes)

# 现在只有 fc 层可以训练
print(f"可训练参数：{sum(p.numel() for p in model.parameters() if p.requires_grad):,}")
```

**适用场景**：
- ✅ 数据量非常小（<500 张）
- ✅ 目标领域与 ImageNet 相似
- ✅ 计算资源有限

### 3.2 策略 2：微调（Fine-tuning）

**方法**：
- 解冻部分卷积层
- 同时训练卷积层和分类层
- 使用较小的学习率

**架构**：
```
输入图像
    ↓
[浅层 CNN] (冻结)
    ↓
[深层 CNN] (微调)
    ↓
[新分类器] (训练)
    ↓
输出类别
```

**代码示例**：
```python
# 冻结所有层
for param in model.parameters():
    param.requires_grad = False

# 解冻最后几个卷积层
for param in model.layer4.parameters():
    param.requires_grad = True

# 训练分类层
for param in model.fc.parameters():
    param.requires_grad = True

print(f"可训练参数：{sum(p.numel() for p in model.parameters() if p.requires_grad):,}")
```

**适用场景**：
- ✅ 数据量中等（500-5000 张）
- ✅ 目标领域与 ImageNet 有差异
- ✅ 追求更高准确率

### 3.3 策略 3：全量微调（Full Fine-tuning）

**方法**：
- 解冻所有层
- 训练整个网络
- 使用非常小的学习率

**代码示例**：
```python
# 解冻所有层
for param in model.parameters():
    param.requires_grad = True

# 使用很小的学习率
optimizer = torch.optim.SGD(
    model.parameters(),
    lr=1e-5,  # 非常小的学习率
    momentum=0.9
)
```

**适用场景**：
- ✅ 数据量大（>5000 张）
- ✅ 目标领域与 ImageNet 差异大
- ✅ 计算资源充足

## 4. 特征提取实战

### 4.1 完整代码示例

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms, models
from tqdm import tqdm
import os

class FeatureExtractor:
    """特征提取器"""
    
    def __init__(self, model_name='resnet50', num_classes=2):
        self.device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
        
        # 加载预训练模型
        if model_name == 'resnet50':
            self.model = models.resnet50(
                weights=models.ResNet50_Weights.IMAGENET1K_V1
            )
        
        # 冻结所有层
        for param in self.model.parameters():
            param.requires_grad = False
        
        # 替换分类层
        num_features = self.model.fc.in_features
        self.model.fc = nn.Linear(num_features, num_classes)
        
        self.model = self.model.to(self.device)
        print(f"模型创建完成！可训练参数：{self.count_parameters():,}")
    
    def count_parameters(self):
        return sum(p.numel() for p in self.model.parameters() if p.requires_grad)
    
    def train(self, train_loader, val_loader, num_epochs=10):
        """训练分类器"""
        criterion = nn.CrossEntropyLoss()
        optimizer = torch.optim.Adam(
            self.model.fc.parameters(),
            lr=0.001
        )
        
        best_acc = 0.0
        
        for epoch in range(num_epochs):
            print(f"\nEpoch {epoch+1}/{num_epochs}")
            
            # 训练
            self.model.train()
            running_loss = 0.0
            correct = 0
            total = 0
            
            pbar = tqdm(train_loader, desc='Training')
            for images, labels in pbar:
                images = images.to(self.device)
                labels = labels.to(self.device)
                
                optimizer.zero_grad()
                outputs = self.model(images)
                loss = criterion(outputs, labels)
                loss.backward()
                optimizer.step()
                
                running_loss += loss.item()
                _, predicted = outputs.max(1)
                total += labels.size(0)
                correct += predicted.eq(labels).sum().item()
            
            train_loss = running_loss / len(train_loader)
            train_acc = 100. * correct / total
            
            # 验证
            self.model.eval()
            val_loss = 0.0
            correct = 0
            total = 0
            
            with torch.no_grad():
                for images, labels in val_loader:
                    images = images.to(self.device)
                    labels = labels.to(self.device)
                    outputs = self.model(images)
                    loss = criterion(outputs, labels)
                    
                    val_loss += loss.item()
                    _, predicted = outputs.max(1)
                    total += labels.size(0)
                    correct += predicted.eq(labels).sum().item()
            
            val_acc = 100. * correct / total
            print(f"训练准确率：{train_acc:.2f}%, 验证准确率：{val_acc:.2f}%")
            
            if val_acc > best_acc:
                best_acc = val_acc
                torch.save(self.model.state_dict(), 'best_model.pth')
                print(f"✨ 保存最佳模型！")
        
        print(f"\n最佳验证准确率：{best_acc:.2f}%")
        return best_acc

# 使用示例
if __name__ == '__main__':
    # 数据变换
    transform = transforms.Compose([
        transforms.Resize((224, 224)),
        transforms.ToTensor(),
        transforms.Normalize([0.485, 0.456, 0.406], 
                           [0.229, 0.224, 0.225])
    ])
    
    # 加载数据集
    train_dataset = datasets.ImageFolder('data/train', transform=transform)
    val_dataset = datasets.ImageFolder('data/val', transform=transform)
    
    train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
    val_loader = DataLoader(val_dataset, batch_size=32, shuffle=False)
    
    # 创建特征提取器
    extractor = FeatureExtractor(model_name='resnet50', num_classes=2)
    
    # 训练
    extractor.train(train_loader, val_loader, num_epochs=10)
```

### 6.2 学习率策略

```python
# 学习率预热
class WarmupScheduler:
    def __init__(self, optimizer, warmup_epochs=5):
        self.optimizer = optimizer
        self.warmup_epochs = warmup_epochs
        self.base_lrs = [group['lr'] for group in optimizer.param_groups]
    
    def step(self, epoch):
        if epoch < self.warmup_epochs:
            # 预热阶段：线性增加
            factor = (epoch + 1) / self.warmup_epochs
            for i, group in enumerate(self.optimizer.param_groups):
                group['lr'] = self.base_lrs[i] * factor
        else:
            # 正常衰减
            pass

# 使用
scheduler = WarmupScheduler(optimizer, warmup_epochs=5)
```

### 6.3 早停策略

```python
class EarlyStopping:
    def __init__(self, patience=10, min_delta=0.001):
        self.patience = patience
        self.min_delta = min_delta
        self.counter = 0
        self.best_loss = None
        self.early_stop = False
    
    def __call__(self, val_loss):
        if self.best_loss is None:
            self.best_loss = val_loss
        elif val_loss > self.best_loss - self.min_delta:
            self.counter += 1
            if self.counter >= self.patience:
                self.early_stop = True
        else:
            self.best_loss = val_loss
            self.counter = 0

# 使用
early_stopping = EarlyStopping(patience=10)
for epoch in range(num_epochs):
    # 训练...

        print("早停！")
        break
```
