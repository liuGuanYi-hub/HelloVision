## 📚 学习内容

### 1. Python 简介与环境配置
- 为什么选择 Python
- 环境安装和配置
- 编辑器选择

### 2. 基础语法
- 变量和数据类型
- 基本运算
- 字符串操作

### 3. 数据结构
- 列表（List）
- 字典（Dictionary）
- 元组（Tuple）
- 集合（Set）

### 4. 控制流程
- 条件语句（if-elif-else）
- for 循环
- while 循环

### 5. 函数
- 定义和调用
- 参数传递
- Lambda 函数
- 作用域

### 6. 模块和包
- 导入模块
- 常用标准库
- 第三方库安装

### 7. 文件操作
- 读写文件
- 文件模式
- 路径处理

### 8. 异常处理
- try-except
- 抛出异常
- 错误处理最佳实践

### 9. 面向对象编程
- 类和对象
- 继承
- 特殊方法

### 10. 常用库简介
- NumPy（数值计算）
- Pandas（数据分析）
- Matplotlib（可视化）
- OpenCV（图像处理）
