# HelloWorld Vision

HelloWorld Vision 是一个计算机视觉学习与实战项目集合，从 Python 基础、传统图像处理到深度学习与完整 CV 项目，按阶段沉淀学习笔记、练习代码和实验规划。

## 学习路径

- Stage 1：Python 基础
- Stage 2：传统图像处理
- Stage 3：现代深度学习视觉
- Stage 4：实战项目与进阶应用

## 当前重点

`Stage4_Practical_Projects_Advanced` 汇总了图像分类、目标检测、图像分割、迁移学习、风格迁移和综合项目等实践方向。

## 项目结构

```text
HelloWorld_Vision/
├── Stage1_Python_Fundamentals/
├── Stage2_Traditional_Image_Processing/
├── Stage3_Deep_Learning_Modern_CV/
└── Stage4_Practical_Projects_Advanced/
```

## 环境与运行

```bash
cd Stage4_Practical_Projects_Advanced
pip install -r requirements.txt
```

更多环境说明和项目进度见各阶段目录下的 `README.md`。

## 目标

- 系统补齐 CV 基础能力
- 完成可展示的视觉实战项目
- 记录训练、评估、调参与可视化过程
- 为后续作品集和技术博客沉淀素材
